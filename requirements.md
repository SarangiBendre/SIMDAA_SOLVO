Project Name:
SIMDAA SOLVO

Tagline:
Ask. Solve. Share.

Objective:
Create an internal knowledge-sharing and doubt-resolution platform for Simdaa Technologies where employees, trainees, interns, and mentors can ask questions, share solutions, and build a reusable knowledge base.

Technology Stack:
Frontend: React + Vite
Backend: FastAPI
Database: SQL Server
AI: Ollama
Version Control: GitHub

Authentication:
Admin-created username and password.

Notifications:
Outlook email notifications for new questions and answers.
